# Floor Inspectors — WoW Forever Countdown

A lightweight, mobile-friendly countdown page for the guild.

## Publishing

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` will deploy the site on pushes to `main`.

The published address will be:

https://rickors91-droid.github.io/floor-inspectors-forever/

The countdown target is 4 November 2026 at 23:00 UTC. The page runs entirely in the visitor's browser; there is no server to pay for.
